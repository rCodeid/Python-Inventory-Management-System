# Python Inventory Management System

A simple inventory management system built using Python. This project allows users to manage warehouse stock through a simple menu-based program.

## Features

- Enter initial stock quantity
- Enter warehouse date
- Add product stock
- Reduce product stock
- View current stock
- Display transaction information
- Validate menu selection
- Exit the program

## Technologies Used

- Python
- While Loop
- If, Elif, Else
- Input and Output
- Datetime Module

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

```bash
python stok_gudang.py
```
